# 204 次独立集群切主

102 组配置对照，每组在两个独立 kind 集群删除主库 Pod，终止宽限 5 秒。按客户端确认序号核对新主库和下游订阅者。报告时间从删除请求计起，包含轮询与客户端采样耗时。

| 逻辑槽 | 次数 | 新主库恢复上界 P50 | 下游恢复上界 P50 / P95 | 下游查回确认事务 |
|---|---:|---:|---:|---:|
| 普通槽 | 102 | 23.44 s | 0/102 在观察窗口内续传 | 306/550 |
| failover slot | 102 | 23.38 s | 28.32 / 28.84 s | 557/557 |

新主库查回全部 1,107 笔确认事务。普通槽组观察截止时间中位数为故障后 114.19 秒，缺失 244 笔指下游在该时点未查到。P95 为线性插值样本分位数。适用于单节点 kind 的 Pod 级故障。
